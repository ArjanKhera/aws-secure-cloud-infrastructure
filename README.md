# Secure Cloud Infrastructure Design & Implementation

Cloud security project focused on designing and implementing a proof of concept cloud solution based on a clients needs. Solution intended to be a secure, scalable and highly available AWS environment.

### Learning Objectives
* Implement secure systems architecture principles and policies applying relevant governance practices.
* Examine the security of a cloud-based virtualized architecture to protect data, application and services.
* Demonstrate cybersecurity controls and techniques in the design of an organization's system architecture.
* Develop professional plan documentations and communication skills relevant to the field of Security Architecture.
* Discuss ethical and sustainable considerations related to different security architectural models.

### Deliverables
* Detailed AWS Architecture Diagram
* Proof of Concept Implementation and explanation
* Justification of Additional AWS Services (Beyond PoC)
* Sustainability (AWS Well-Architected Framework)
* Presentation - WinLocal Security & NIST CSF 2.0 (Stakeholder presentation, non-technical language)

### Technologies
* AWS
* Security Groups
* Network Security & Segmentation
* Auto Scaling Policies
* IAM
* Load Balancing
* Cloud Architecture
